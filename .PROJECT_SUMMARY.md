## Notes for Future Development

1. **Auth Tokens**: JWT stored in localStorage, auto-injected in API calls
2. **Error Handling**: 401 errors clear token and redirect to login
3. **Role Based**: Use `<ProtectedLayout requiredRole="admin">` for access control
4. **API Calls**: Use `lib/api.ts` endpoints, never call backend directly
5. **TypeScript**: Keep type safety - no `any` types without reason
6. **Styling**: All Tailwind, no inline CSS
7. **Components**: Use components for reusable UI
8. **Environment**: Use .env.local, never commit secrets
